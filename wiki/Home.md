# Disk Analyzer

**Windows 디스크를 빠르게 스캔하고, 무엇이 공간을 차지하는지 한눈에 보여주는 프로그램입니다.**

![메인 화면](docs/images/main-preview.png)

- ⚡ **NTFS `$MFT` 직접 파싱**으로 대용량 디스크도 빠르게 스캔
- 🌳 **Folder / Treemap / Sunburst** 세 가지 시각화를 자유롭게 전환
- 🧹 삭제 안전성을 **P0~P3 등급**으로 나눠 위험한 삭제를 예방
- 🚚 찾은 파일을 그 자리에서 바로 옮기는 **빠른 이동(Quick Move)**
- 📦 별도 설치 없이 실행 파일 하나로 동작 (**self-contained**)

| 항목 | 내용 |
|---|---|
| 지원 OS | Windows 10 / 11 (x64) |
| 실행 환경 | .NET 9 (self-contained 배포본은 런타임 설치 불필요) |
| 권한 | 관리자 권한 없이도 전체 기능 사용 가능 (Fast Scan만 관리자 권한 필요) |

## 🖥️ 프로그램 전체 화면

![메인 화면 전체](docs/images/main-preview.png)

한 화면에서 다음을 모두 확인할 수 있습니다.

- 왼쪽 **저장소 사이드바**: 드라이브 목록, 사용률, 즐겨찾기(고정한 스캔 대상)
- 상단 **탭**: 폴더 / Treemap / 선버스트 / 큰 파일 / 파일 유형 / 정리 추천 / 빠른 이동
- 탭 위 **경로 막대(breadcrumb)**와 뒤로·앞으로·상위 이동 버튼
- 하단 **상태바**와 실시간 스캔 진행 패널

## 📁 Folder View

![Folder View](docs/images/folder-view.png)

탐색기와 비슷한 목록 형태로 폴더/파일을 크기 순으로 보여줍니다. 각 항목의 점유율은 막대 그래프로 함께 표시됩니다.

### 주요 특징

- 크기·이름·수정일 등 정렬 기준 선택
- 폴더를 더블 클릭하면 그 안으로 들어가고, 상위/뒤로/앞으로 버튼으로 자유롭게 이동
- Ctrl / Shift 로 여러 항목을 한 번에 선택해 일괄 삭제 가능
- 폴더를 열 때 실제 파일 시스템과 비교해 변경된 부분을 알려주고 **F5**로 새로고침

## 🌐 Treemap

![Treemap](docs/images/treemap.png)

전체 공간을 사각형 블록으로 표현해 **어떤 폴더/파일이 가장 큰지 시각적으로** 바로 알 수 있습니다.

### 주요 특징

- squarified 배치 + 카테고리별 색상 + 깊이에 따른 명암 차이
- 블록을 더블 클릭하면 탭을 바꾸지 않고 그 폴더 안으로 들어감
- Folder View에서 고른 항목은 Treemap에서 테두리로 강조되고, 반대로도 동일하게 연동

## ☀️ Sunburst (선버스트)

![Sunburst](docs/images/sunburst.png)

동심원 형태로 폴더 구조를 표현합니다. 안쪽 원일수록 상위 폴더, 바깥쪽일수록 하위 폴더입니다.

### 주요 특징

- 조각을 가리키기만 해도 오른쪽 목록이 그 폴더 내용으로 바뀌고, 클릭하면 그 폴더로 진입
- 색상 기준을 세 가지로 전환 가능: **크기 / 정리 추천 점수 / 이전 스캔 대비 증감**
- 너무 작은 항목은 사라지지 않고 "작은 항목 N개"로 합쳐서 표시
- 드라이브 전체를 스캔했다면 목록 아래에 **숨은 공간 / 여유 공간**도 함께 표시

## 🔀 Split View (분할 보기)

![Split View](docs/images/split-view.png)

폴더 목록과 Treemap을 좌우로 나란히 띄워, 목록으로 탐색하면서 동시에 비율을 눈으로 확인할 수 있습니다.

### 주요 특징

- 좌측 폴더 목록 / 우측 Treemap이 항상 같은 폴더를 보여줌 (같은 위치 상태 공유)
- 경계를 드래그해 좌우 폭 조절 가능
- 한쪽에서 항목을 선택하면 다른 쪽에서도 함께 강조

## 📊 Large Files (큰 파일)

![Large Files](docs/images/large-files.png)

디스크 전체에서 용량이 큰 파일들만 뽑아 목록으로 보여줍니다.

### 주요 특징

- 상위 용량 순으로 정렬된 파일 목록
- Ctrl / Shift 다중 선택 + 일괄 삭제 지원
- 새로고침 시 먼저 현재 목록을 실제 상태와 대조하고, 필요하면 전체 재스캔까지 진행

## 🧹 Cleanup Recommendations (정리 추천)

![정리 추천](docs/images/cleanup.png)

"지워도 되는가"(보호 등급)와 "지울 가치가 있는가"(정리 점수)를 **완전히 분리**해서 안내합니다.

### 주요 특징

- 삭제 위험도를 **P0(절대 보호) ~ P3(일반 파일)** 4단계로 구분해 위험한 삭제를 원천 차단
- 오래되고, 용량이 크고, 다시 만들 수 있는 캐시/임시 파일일수록 높은 정리 점수 부여
- 모든 추천 항목에는 **왜 추천되었는지 이유가 함께 표시**됨
- 보기 방식 5가지 지원: 폴더 트리(기본, 반복 패턴 자동 접기) / 파일별 / 경로별 / 유형별 / 정리 이유별
- Visual Studio 빌드 산출물, `.git` 크기, 로그 연령 등 개발자 관점 분석 포함

> ⚠️ 이 기능은 삭제를 대신 결정해주지 않습니다. 어떤 파일이 어떤 기준으로 후보에 올랐는지 보여줄 뿐이며, 최종 삭제 여부와 확인은 항상 사용자가 직접 거칩니다.

## 🚚 Quick Move (빠른 이동)

![빠른 이동](docs/images/quick-move.png)

정리 추천이나 큰 파일 탭에서 찾은 항목을, 지우는 대신 다른 위치로 옮기고 싶을 때 사용합니다.

### 주요 특징

- 출발지 / 목적지 두 패널 + 아래쪽 **이동 대기열**: 항목을 고르면 바로 옮기지 않고 대기열에 쌓아 두었다가 한 번에 처리
- 같은 드라이브면 즉시 이동(이름 바꾸기), 다른 드라이브면 복사 후 원본 삭제(진행률 · 취소 · 일시정지 지원)
- 이동 전 자동 검사: 쓰기 권한, 자기 하위 폴더로 이동 방지, 보호 등급 경고, 대상 드라이브 여유 공간 확인
- 이름 충돌 시 확인 / 건너뛰기 / 새 이름 / 덮어쓰기 선택 가능
- 다른 분석 탭 옆에 붙는 좁은 **도크 형태**로도 사용 가능 (탭을 벗어나지 않고 바로 이동)

## 🧭 Path Navigation

![경로 탐색](docs/images/path-navigation.png)

모든 탭이 공유하는 경로 막대(breadcrumb)로 어디에 있는지 항상 확인할 수 있습니다.

### 주요 특징

- 뒤로 / 앞으로 / 상위 / 루트 이동 버튼
- 경로를 직접 입력할 수 있는 편집 모드 (✎ 아이콘 또는 `Ctrl+L`) — 붙여넣기, 환경변수, `Tab` 자동완성 지원
- 스캔 범위를 벗어난 경로를 입력하면 **[이 경로 스캔]** 등 대안을 안내
- ☆ 즐겨찾기 추가(`Ctrl+D`)로 자주 가는 폴더를 저장 — 빠른 이동 탭과 목록 공유

## ✅ Multi Selection / Batch Delete

폴더 탭과 큰 파일 탭 모두 탐색기와 같은 방식으로 다중 선택을 지원합니다.

### 주요 특징

- `Ctrl+클릭` / `Shift+클릭` / `Ctrl+A`로 여러 항목 선택
- 선택한 개수와 총 용량을 하단에 항상 표시 (폴더 탭은 폴더/파일 개수 구분 표시)
- 폴더를 선택하면 하위 전체가 삭제 대상이 되며, 확인 창을 열기 전에 하위를 훑어 가장 높은 보호 등급을 자동으로 매김
- 삭제 버튼을 눌러도 즉시 지우지 않고 반드시 **확인 창**을 거침 (등급별 경고, 개별 제외, 최종 재검증 후 삭제)
- 기본은 휴지통 이동이며, 영구 삭제는 별도 버튼과 2단계 확인 필요

## 🔗 기능 간 연동

Disk Analyzer의 여러 화면은 서로 독립적이지 않고 하나의 "현재 위치"를 공유합니다.

- **Folder View ↔ Treemap ↔ Sunburst**: 세 화면 모두 같은 경로 상태를 공유하며, 한쪽에서 이동하면 나머지도 같은 폴더를 가리킵니다.
- **Breadcrumb / 뒤로·앞으로·상위**: 어느 탭에 있든 동일한 경로 막대와 이동 버튼을 사용합니다.
- **선택 항목 강조**: 목록에서 고른 항목이 Treemap·Sunburst에서 테두리/포커스로 함께 표시됩니다.
- **Split View**: 목록과 Treemap을 동시에 보면서 탐색할 수 있습니다.
- **정리 추천 → Quick Move**: 정리 후보로 찾은 파일을 삭제 대신 다른 드라이브로 옮길 수 있습니다.

## 💾 설치 및 실행

### 1) 배포본 실행 (권장)

1. [Releases](../../releases) 페이지에서 최신 `DiskAnalyzer.exe`를 내려받습니다.
2. 별도 설치 과정 없이 실행 파일을 원하는 위치에 두고 바로 실행합니다.

- **단일 파일 · self-contained** 배포본이라 **.NET 런타임을 따로 설치할 필요가 없습니다.**
- 일반 권한으로 실행해도 모든 기능을 사용할 수 있습니다. (NTFS Fast Scan만 관리자 권한이 필요하며, 없으면 자동으로 Compatibility 방식으로 전환됩니다.)

### 2) 직접 빌드하기

빌드에는 **.NET 9 SDK**가 필요합니다(런타임만으로는 빌드할 수 없습니다).

```bash
dotnet build DiskAnalyzer.sln -c Release
```

배포용 단일 실행 파일 만들기:

```bash
dotnet publish src/DiskAnalyzer.App/DiskAnalyzer.App.csproj -c Release -r win-x64 \
  --self-contained true -p:PublishSingleFile=true \
  -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:DebugType=none -o dist
```

## 🚀 성능 / 내부 구조 (간단히)

깊은 내부 구조는 다루지 않고, 이해에 필요한 정도만 정리했습니다. 자세한 내용은 [Technical Details](Technical-Details) 페이지를 참고하세요.

- **NTFS `$MFT` 기반 Fast Scanner**: 파일 시스템을 폴더 단위로 일일이 열거하지 않고, NTFS의 메타데이터 영역(`$MFT`)을 직접 읽어 훨씬 빠르게 스캔합니다. (관리자 권한 필요)
- **Compatibility Scanner**: Fast Scan이 불가능한 경우(비 NTFS, 권한 없음, 하위 폴더 스캔 등) 자동으로 전환되는 일반 폴더 탐색 방식입니다.
- **대용량 디스크 대응**: 수천만 개의 파일이 있는 드라이브도 스캔할 수 있도록 메모리 사용량을 최소화한 자료구조를 사용합니다.
- **UI와 스캔 엔진 분리**: 스캔 작업은 백그라운드에서 진행되며, 화면은 일정 주기로 진행 상황만 전달받아 갱신되므로 스캔 중에도 UI가 멈추지 않습니다.

## 🛡️ 안전한 파일 정리

Disk Analyzer는 "이 파일을 지우세요"라고 단정하지 않습니다. 대신 **얼마나 위험한 삭제인지**를 등급으로 알려주고, 실수를 막는 장치를 여러 겹으로 둡니다.

| 등급 | 의미 | 기본 동작 |
|---|---|---|
| **P0** | 절대 보호 | 선택/삭제 자체가 불가능 (예: 페이지 파일, 시스템 핵심 폴더, 부팅 영역) |
| **P1** | 고위험 | 기본적으로 선택 해제 상태, 강한 경고 후에만 삭제 가능 (예: Program Files, AppData) |
| **P2** | 정리 가능 | 조건을 만족하면 정리 후보로 추천 (예: Temp, Cache, 오래된 로그) |
| **P3** | 일반 파일 | 일반적인 삭제 대상 (예: 다운로드, 문서, 압축 파일) |

- 삭제 버튼을 눌러도 곧바로 지워지지 않고, 항상 **확인 창**을 거칩니다.
- 확인 창에서는 파일별 보호 등급과 경고를 보여주고, 항목을 개별적으로 제외할 수 있습니다.
- 실제 삭제 직전에 **한 번 더 보호 등급을 재검증**해, 그 사이 상태가 바뀐 파일은 안전하게 제외합니다.
- 기본 삭제는 **휴지통 이동**이며, 영구 삭제는 별도의 강한 경고와 2단계 확인을 거칩니다.

## ❓ FAQ

**Q. 관리자 권한이 꼭 필요한가요?**
아니요. 일반 권한으로 실행해도 모든 기능을 사용할 수 있습니다. 다만 드라이브 루트를 스캔할 때 NTFS Fast Scan을 쓰려면 관리자 권한이 필요하며, 없으면 자동으로 Compatibility 방식으로 전환됩니다.

**Q. .NET 설치가 필요한가요?**
배포본(`dist/DiskAnalyzer.exe`)은 단일 파일 · self-contained 방식이라 별도의 .NET 런타임 설치가 필요 없습니다. 소스에서 직접 빌드하려면 .NET 9 SDK가 필요합니다.

**Q. NTFS가 아닌 드라이브에서도 동작하나요?**
네. NTFS가 아니거나 Fast Scan이 불가능한 경우 자동으로 일반 폴더 탐색 방식(Compatibility Scanner)으로 전환되어 동작합니다.

**Q. 삭제 기능은 안전한가요?**
삭제는 보호 등급(P0~P3)에 따라 제한되며, 시스템 핵심 파일(P0)은 선택 자체가 불가능합니다. 삭제 전에는 항상 확인 창을 거치고, 삭제 직전에 한 번 더 재검증합니다. 기본은 휴지통 이동이며 영구 삭제는 추가 확인이 필요합니다.

**Q. 스캔 중에 취소할 수 있나요?**
네. 스캔은 재귀 함수가 아니라 큐 기반 구조로 동작하기 때문에 취소 요청이 즉시 반영됩니다.

**Q. 대용량 디스크(수천만 개 파일)에서도 쓸 수 있나요?**
네. 파일 수천만 개 규모의 디스크에서도 동작하도록 메모리 사용량을 최소화해 설계되었습니다.

**Q. 정리 추천이 파일을 자동으로 지우나요?**
아니요. 정리 추천은 "지울 가치가 있는 후보"를 점수와 이유로 보여줄 뿐이며, 실제 삭제는 항상 사용자가 직접 확인하고 실행해야 합니다.

**Q. 단축키를 바꿀 수 있나요?**
네. 설정 패널의 [단축키 설정...]에서 대부분의 단축키를 원하는 조합으로 변경할 수 있습니다.
